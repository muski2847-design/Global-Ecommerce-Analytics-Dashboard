# Global E-Commerce Analytics Dashboard
## Overview
The **Global E-Commerce Analytics Dashboard** is an interactive Power BI project created using a sample global e-commerce dataset. The objective of this project is to present sales-related information in a clear and visually engaging dashboard that enables users to explore key business metrics and performance trends.

The dashboard provides a consolidated view of important KPIs, including Total Sales, Total Profit, Quantity Sold, Average Discount, Average sales and Total Orders. It also includes multiple visualizations to analyze sales by category, country-wise profit, sales trends over time, shipping mode performance, and customer payment methods.

Interactive slicers for **Category** and **Shipping Mode** allow users to filter the dashboard dynamically, making it easier to compare different segments and gain meaningful insights from the data. This project demonstrates the use of Power BI for creating interactive dashboards and presenting business data in an easy-to-understand format.
